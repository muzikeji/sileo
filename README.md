# 木子源（Muzi Sileo Repo）

MUtool 多功能工具集越狱源。添加源：`https://muzikeji.github.io/sileo/`

## 功能简介

- 灵动岛电池胶囊：长按状态栏电池弹出完整电池信息，真机机型贴合挖孔展开，锁屏充电常驻大字电量/预计充满
- 悬浮信息药丸：实时网速 / CPU / 内存 / 时间 / 电池，Liquid Glass 风格，拖动持久化
- 状态栏图标分色与 VPN 变色：时间/信号/Wi-Fi/蜂窝文字/电池单独配色，VPN 连接时网络图标自动变色
- 5G Advanced：将 5G 显示为 5Gᴀ
- 充电限制：限充阈值、阻止充电、智能计划、智能温度停充
- 温控调校：阻止降频、CPU 功率锁定、模拟降频
- 通话自动录音、录屏增强、定时任务、自动禁用 SIM 与卡槽管理、三合一状态栏、电池健康

支持 rootless / roothide，iOS 15-17。
